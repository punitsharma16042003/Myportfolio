## ✏️ How to Easily Edit or Add New Content

All data is stored cleanly inside a single file: **`portfolio-data.js`**.
You do **not** need to touch any HTML or CSS files.

### Method 1: Using the Built-in Visual Generator (Recommended)
1. Open the website in your browser.
2. Click the **"➕ Add Entry"** button in the top navigation bar.
3. Select what you want to add:
   - Certificate / Training
   - Publication / Preprint
   - GitHub Project
   - Lab Research Project
4. Fill in the title, organization/journal, year, and description.
5. Click **"👁️ Live Preview on Page"** to see how it looks immediately on your live site!
6. Click **"📋 Copy Code Snippet"** and paste it into the matching section in `portfolio-data.js`.

### Method 2: Direct Edit in `portfolio-data.js`
Open `portfolio-data.js` in VS Code or any text editor. Each section is clearly separated:
- Replace placeholder links (Google Scholar, ORCID)
- Add papers to `publications: [ ... ]`
- Add projects to `projects: [ ... ]` or `githubProjects: [ ... ]`
- Add certificates to `certificates: [ ... ]`

Save the file and refresh your browser!

## 🌐 How to Deploy to GitHub Pages (Free)

1. Go to [GitHub](https://github.com/new) and create a repository named:
   ```
   punitsharma16042003.github.io
   ```
2. Upload or push all files in this folder (`index.html`, `portfolio-data.js`, `resume.pdf`, `css/`, `js/`) to the root of the repository.
3. Go to **Settings** &rarr; **Pages**, select branch `main` and folder `/ (root)`, and click **Save**.
4. Your website will be live in ~60 seconds at:
   ```
   https://punitsharma16042003.github.io
   ```
